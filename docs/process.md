# Process summary

I used Codex to research, explore and build the prototype directly in code, with no Figma mockups. I audited the live DeoVR experience and its catalogue, then compared three coded directions: a cinematic streaming layout, a focus-led Viewfinder and an immersion-aware Field Guide. I chose the Viewfinder stage with the Field Guide's grid and filters, keeping the catalogue easy to scan while making immersive format and comfort visible before a watch decision.

The highest-impact changes are the featured experience stage, the consistent Immersion Signature for field of view, depth, clarity, frame rate and estimated camera motion, and a pre-flight quick view with comfort warnings. Search, subject filters and format filters make discovery more direct. A local headset queue and a larger-target headset mode show how desktop browsing can hand off to immersive viewing.

The working prototype uses Next.js, React, TypeScript and Tailwind CSS with real DeoVR catalogue data and media. More time would go toward reviewing the rendered layouts on desktop, mobile and a Quest headset, adding high-resolution stage loops for more featured videos, validating the motion estimates with creators, and testing the discovery hierarchy with viewers.
